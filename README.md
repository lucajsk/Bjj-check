# BBJ Check

Forschungsprototyp zur Fehlererkennung beim HYROX Burpee Broad Jump (Doppelsprung, Overstepping), live über die Kamera oder aus einem Video.

Die Analyse läuft lokal im Browser mit Google MediaPipe Pose Landmarker. Videos werden nicht hochgeladen.

Hinweis: Prototyp, noch nicht mit echten Aufnahmen validiert. Ergebnisse immer mit einer menschlichen Bewertung abgleichen.
